## ps

Codeforces 580c가 그래프(트리)를 순회하는 문제였는데, 각 노드의 값이 0 혹은 1이라서 `bool` 타입 벡터를 사용하고 입력을 받으려 했다.

```cpp
vector<bool> a(n);

for (bool& ai: a) {
    std::cin >> ai;
}
```

아무런 이상이 없는 코드라고 생각했지만, 컴파일 에러가 생겼다. 이유를 조금 찾아보고 정리를 했는데 다음과 같다.

1. `bool` 타입을 원소로 가지는 벡터는 다른 벡터들과 다르게 각 원소를 1비트 단위로 압축해서 저장한다. (ex: `1010101...`)
2. 압축되어 저장되었기 때문에(그냥 비트에 녹아버렸으니까) 다른 타입의 벡터와 서브스크립트 접근 방식이 달라야 한다. 
3. 이를 해결하기 위해서 프록시 객체가 존재한다. `a[3] = true;` -> `a.operator[](3).operator=(true);`
4. 만약 `bool&`을 통해 레퍼런스를 뽑아내려 하면, 프록시 객체 자체가 리턴된다.
5. 결론적으로 `vector<bool>`에선 위의 코드같은 문법을 못 쓴다...

위와 같은 경우가 아니더라도, 굳이 `bool` 타입 벡터를 쓸 필요도 없는게, 프록시 객체가 원소를 뽑아오는 것도 다른 벡터보다 더 많은 계산 시간이 필요하다. 그래서 그냥 `int` 벡터로 문제를 풀었다.
