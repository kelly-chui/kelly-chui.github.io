## 배운 내용

### SwiftUI Essentials

WWDC 세션을 하나 봤다. 이번에는 SwiftUI의 기본 구조를 다시 정리하는 내용이었는데, 핵심은 `View`가 실제 UI 객체를 직접 만지는 대상이 아니라 선언형으로 UI를 설명하는 값이라는 점 이었다(Demystify SwiftUI도 마찬가지고 엄청나게 반복되는 내용이다.)

사용하는데 익숙한 `View`나 `Modifier`는 당연하고, 가장 설명 중 좋았던 부분은 적응형 view였다. UIKit처럼 모든 모양과 동작을 직접 다 잡는 게 아니라, SwiftUI는 환경에 맞는 표현을 어느 정도 스스로 선택한다. UI 프레임워크에서 명령형과 선언형의 차이를 가장 확실하게 보여주는 부분이라 생각했다.
